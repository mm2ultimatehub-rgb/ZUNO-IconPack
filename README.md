# ZUNO Icon Collection

Original launcher icon variations designed and maintained by **ZUNO Studio** for the ZUNO music player.

Every option uses the same recognizable ZUNO waveform mark, with a different color treatment:
- ZUNO Pure
- ZUNO Midnight
- ZUNO Coral
- ZUNO Aurora
- ZUNO Graphite
- ZUNO Mint

The icon source files are in `svg/`; `metadata.json` is the catalog consumed by the Android build.

These are first-party ZUNO designs, not community-submitted third-party icon packs.

Repository: https://github.com/mm2ultimatehub-rgb/ZUNO
